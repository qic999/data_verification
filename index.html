FILTERING POLICY

Data filtering rules

数据过滤规则

Known format, coordinate-axis, and scale conventions are corrected first. Only residual cases that meet a dataset-specific hard rule are filtered; borderline cases remain in the data and are sent to human review. 首先修正已知的数据格式、坐标轴和尺度约定。只有修正后仍满足数据集专用 hard rule 的样本才会被过滤；边界样本继续保留，并进入人工复核。

01

Normalize and repair

标准化并修正

Load with the current training loader, convert boxes to the camera frame, apply known axis/handedness fixes, and verify finite positive geometry.

使用当前训练 loader，将框转换到相机坐标系，应用已知的坐标轴和手性修正，并检查几何量有限且为正。

Measure projection consistency

计算投影一致性

Compare the visible 2D box with the projected 3D box using one-way containment.

用单向包含率比较可见 2D 框与投影 3D 框。
03

Hard failure → Filtered

严重错误 → 过滤

Invalid geometry or a metric beyond a hard threshold is excluded from training and recorded in the deletion/filter manifest.

无效几何或超过 hard threshold 的样本不再参与训练，并记录到删除或过滤清单。
04

Borderline → Human review

边界样本 → 人工复核

A review threshold is a screening signal only. The sample is not deleted unless visual inspection confirms an annotation error.

review threshold 只用于筛查。除非可视化人工确认标注错误，否则样本不会被删除。

2D box calculated from 3D由 3D 框计算的 2D 框 Compare a separately stored projected 2D box with a 2D box recomputed from the 3D box. Hard: exact projection error > 1 px; IoU < 0.15 with normalized-size guard ≥0.05; center > 0.20; or jointly IoU < 0.25 and center > 0.10. 将单独存储的投影 2D 框与从 3D 框重算的 2D 框比较。Hard：精确投影误差 > 1 px；在归一化尺寸至少为 0.05 时 IoU < 0.15；中心偏差 > 0.20；或同时满足 IoU < 0.25 与 中心偏差 > 0.10。 If not hard-filtered: IoU < 0.40 or center > 0.05. Applies to CA-1M, HyperSim, ADT, HOPE Image/Video, Objectron, and SceneVersepp; documented legacy projection errors may remain diagnostic-only. 未达到 hard rule 时，IoU < 0.40 或 中心偏差 > 0.05 进入人工复核。适用于 CA-1M、HyperSim、ADT、HOPE Image/Video、Objectron 和 SceneVersepp；已记录的旧版近似投影误差可只作为诊断。
Visible 2D box可见 2D 框 Compute visible containment = area(visible ∩ projected) / area(visible), preferably with exact mask pixels. Hard: containment < 0.50. Visible-to-amodal IoU and center offset never trigger rejection. 计算 visible containment = area(visible ∩ projected) / area(visible)，优先使用精确 mask pixels。Hard：包含率 < 0.50。Visible-to-amodal IoU 与中心偏差绝不直接触发过滤。 If not hard-filtered: containment < 0.90. Applies to Pix3D, Structured3D, 3D-FRONT, Kubric, uCO3D, ABO, ShapeNet, Replica v2, SUN RGB-D, Synscapes, ATEK, and ScanNet++. Dataset-specific exact-geometry checks remain active. 未达到 hard rule 时，包含率 < 0.90 进入人工复核。适用于 Pix3D、Structured3D、3D-FRONT、Kubric、uCO3D、ABO、ShapeNet、Replica v2、SUN RGB-D、Synscapes、ATEK 和 ScanNet++；数据集专用的精确几何检查继续保留。
Mixed 2D box sources混合 2D 框来源 Check each image or video frame before applying thresholds. A 2D box within 2 px of the stored 3D projection is treated as a box calculated from 3D; a box from a render or mask is treated as visible. 逐图像或视频帧判断后再应用阈值。与存储 3D 投影相差不超过 2 px 的 2D 框视为由 3D 计算；来自 render 或 mask 的框视为可见框。 Omni3D, HSSD, HOI4D, and WildDet3D are mixed. ProcTHOR remains unclassified until its source package is restored. Every image or video frame should ultimately store box_2d_source = mask | tight | trunc | projected. Omni3D、HSSD、HOI4D 和 WildDet3D 属于混合语义。ProcTHOR 在源数据恢复前保持未分类。最终每张图像或视频帧都应保存 box_2d_source = mask | tight | trunc | projected。

Metric definitions: IoU and normalized center are decision metrics only for two projected 2D boxes with the same meaning. For a visible 2D box, containment = intersection / visible area is the decision metric. Historical cases from the old mixed-box rule must be checked again before deletion. 指标定义：IoU 和归一化 中心偏差 只用于含义相同的两个投影 2D 框。对可见 2D 框，判定指标为 包含率 = 交集 / 可见面积。旧版混合框规则产生的历史 case 必须重新审查后才能删除。
